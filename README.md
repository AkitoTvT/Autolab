# AutoLab — Business Website Template

A fictional automotive showroom and service center by Marvin Miranda.

## Get started

The folder contains 13 pages with real photographs, vehicle search and filters, individual car and service pages, and a demo inquiry form. All prices, services, and business details are illustrative. Forms do not send data or create bookings.

Upload the contents of this folder to a static web host or a GitHub repository. Keep index.html at the root and preserve all nested folders. For GitHub Pages, select main and / (root) under Settings > Pages.

To preview locally, run `python3 -m http.server 8000` from this folder and open http://localhost:8000. No npm installation is required.

## Editing

Edit index.html for the homepage. Subpages live in cars/, services/, about/, contact/, and credits/. Edit style.css for visuals and app.js for interactions. Keep the relative paths intact. Search metadata is on the car cards in cars/index.html; update card data attributes when changing vehicle names, prices, brands, or body types.

Barlow Condensed headlines and Outfit body fonts are bundled locally, with their SIL Open Font License notices in assets/fonts/. Photography credits and licensing links are in THIRD-PARTY-NOTICES.md and the credits page.

Before using this for a real business, verify all content and assets, replace sample data, connect the form to a real system, and update the demo notices. No backend, payment system, live inventory, or real booking service is included.
